キムワイプ卓球サイト 更新方法
==============================

このフォルダはHTML・CSS・JavaScriptだけで動きます。PHPは不要です。
GitHub Pagesへは、このフォルダの中身をそのままアップロードできます。

■ 日時・料金・参加方法・文章を変える
  index.html をテキストエディタで開き、該当する文字を変更します。

■ 色を変える
css/style.css の先頭にある :root 内を変更します。
--color-blue が主な差し色、--color-bg が背景色です。

■ ロゴを変える
images/logo.png を同じ名前の画像で上書きします。
縦横比の違う画像でも収まる設定です。

■ ヒーロー写真・背景写真を変える
images/hero.jpg を上書きすると、最初に大きく表示される写真が変わります。
images/background.jpg を上書きすると、ヒーロー右側の薄い背景が変わります。

■ その他の写真を変える
images/about.jpg は「キムワイプ卓球とは」の写真です。
images/craft.jpg はペーパークラフトの写真です。

■ 昨年の写真を追加する
1. images/gallery/ に JPG・PNG・WebP 画像を入れます。
2. js/gallery-images.js を開き、説明に従ってファイル名と説明を追加します。
3. 表示順はページを開くたびに自動でランダムになります。

注意：ブラウザの安全制限により、JavaScriptだけでフォルダ内の画像を自動検索することはできません。
そのため、追加時は js/gallery-images.js の一覧も更新します。

■ Font Awesomeについて
アイコンはCDNから読み込むため、表示にはインターネット接続が必要です。
アカウント登録や追加設定は不要です。

■ 公開前に確定が必要な項目
・開催時間
・料金
・申込方法または参加方法
